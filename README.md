## 📌 Deskripsi Proyek
SIP-KTM adalah sistem informasi berbasis web yang memfasilitasi pendataan permohonan Kartu Tanda Mahasiswa (KTM) baru, penggantian karena hilang, maupun penggantian kartu rusak. Sistem ini dilengkapi dengan:
- Formulir pengajuan online mahasiswa
- Kalkulasi otomatis biaya administrasi berdasarkan jenis permohonan
- Pengecekan dan pelacakan status pengajuan (*Real-time Tracking*) menggunakan NIM
- Validasi berkas persyaratan (pas foto & surat kehilangan kepolisian)
- Skema basis data terstruktur dan pemodelan proses bisnis
